# 会議室スタート（MAXHUB の最初の画面・試作）

ソルエイト株式会社が商談用に作った、MAXHUB の電源を入れて最初に出す画面の試作です。1ファイルの HTML で、サーバーを置かずに動きます。

## できること

- **会議をはじめる**：議題ごとの残り時間を大きく表示。話した言葉をその場で字幕にし、字幕にふれると「決まったこと」「宿題」に変えられます。発言から決まったこと・宿題の候補をAIが拾い、終わったら要約つきのまとめをQRコードでスマホに渡します。まとめは繁體中文でも表示できます。
- **イベント・説明会**：来場者がQRを読むと、スマホから質問・いいね・投票・拍手を送れます。質問は司会者が確かめてから公開。話している言葉の字幕（日本語・繁體中文・English）も来場者のスマホに届きます。
- **待機画面**：会議のない時間は、時刻・今日の予定・お知らせを流します。
- **非常時の表示**：地震・火事のときの動き方と、集まる場所・連絡先を大きく出します。

## データの扱い

- 字幕・翻訳・AIの候補・要約は、ブラウザ（Chrome）に内蔵された機能で処理します。端末の中で処理できる場合は端末の中で処理し、声や文字を外へ送りません。端末の中で聞き取れないブラウザでは、ブラウザの音声認識サービスを使います（画面に表示します）。
- イベントの質問・投票は、大画面と来場者のスマホを WebRTC で直接つないでやり取りします。相手を見つけるときだけ公開のリレー（Nostr）を使い、その中身は暗号化されています。質問や投票の内容はサーバーに残りません。
- 会議のまとめは QR コードの中に入れて渡し、サーバーには送りません。
- 表示されている会社名・予定は見本です。
