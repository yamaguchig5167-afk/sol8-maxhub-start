# 会議室スタート（MAXHUB の最初の画面・試作）

ソルエイト株式会社が商談用に作った、MAXHUB の電源を入れて最初に出す画面の試作です。

- 会議をはじめる：議題ごとの残り時間、決まったこと・宿題をその場で残し、終わったらQRコードでスマホに持ち帰れます。
- 待機画面：会議のない時間は、時刻・今日の予定・お知らせを流します。
- 非常時の表示：地震・火事のときの動き方と集まる場所・連絡先を大きく出します。

表示されている会社名・予定は見本です。内容は画面の「表示する内容を変える」から変えられ、その端末のブラウザの中にだけ保存されます。
会議のまとめはQRコードの中に入れて渡し、サーバーには送りません。

QRコード生成には qrcode-generator（Kazuhiko Arase・MIT License）を使っています。
